# RULA｜影片時段負重與肌肉使用＋影像自動計分版（2026-10-30）

**版本標記：`RULA_VIDEO_TIMELINE_AUTO_2026-10-30`**

以最新的「頸部角度可見／照片批次補正選用版」為基礎修改。完整 `222.py` 保留單側／雙側與正面選填、Hand 2D 優先、Pose 2D 備援、原有頸角估算、左右共同頸部分數、嚴重品質複核、人工局部修正、照片與 CSV／ZIP 匯出。

## 這次最重要的修改

- **影片時段設定：** 第 1 頁「上傳影片與作業設定」保留原有的「肌肉使用預設分數」與「負重／施力預設分數」。展開「🕒 依影片時段指定負重與肌肉使用」即可設定最多八個不同的工作階段。每組只需填名稱、開始秒數、結束秒數、肌肉使用 0／1、負重／施力 0～3。時段以「開始含、結束不含」為原則；最後一段在尾端可含結束秒數。不能交疊、不能超過影片長度，錯誤會在分析前擋住。
- **秒數不再混淆：** 雙側模式一律使用**右側原始影片播放秒數**；單側右手使用右側影片，單側左手使用左側影片。假設左右、正面起錄不同步，系統仍會依已確認的同步錨點換算到共同動作。使用者**不需要輸入負的「共同時間」**。
- **沒有指定的秒數：** 直接使用第 1 頁的預設肌肉使用／負重分數，不會隨意補 0 或延續前一時段。
- **同一張照片只採用一組設定：** 每張影格在進入 RULA Table A／B／C 之前就先得到該秒數的 m／f 分數。雙側同步對應相同作業瞬間，左右共用同一組作業時段分數；原本各側的姿勢角度和 RULA 基本分數仍獨立計算。
- **照片批次修改仍保留且為選用：** 先用時段分數分析完整影片，只有少數照片條件不同時，才透過多選照片一次修改。後續修改的肌肉／負重分數優先於影片時段；角度不需要重新跑 MediaPipe，重新執行既有 RULA 查表。
- **簡化一般使用者文字：** 頁面不再要求理解「候選分數」，改顯示「RULA 評分」、「系統評分」、「照片批次修改」及實際採用的設定來源。未經人工驗證的系統結果不能宣稱已驗證準確率。
- **報表追溯：** 在網頁風險總覽可展開本次時段表與每張照片套用結果；一般逐側／雙側 CSV、新的 `評估結果/逐張時段與作業條件.csv`、人工比對空表、批次修改稽核檔都會保留採用分數或來源。

## 搬運作業 21 秒示例

1. 影片上傳完成，先依作業狀況把「肌肉使用預設」和「負重／施力預設」選成適用於**未另指定時段**的值。
2. 展開影片時段，勾選啟用。如果右側原始影片的第 4～12 秒在搬運，可填 `搬運`、開始 `4`、結束 `12`，並依重量／施力方式指定 0～3 分。
3. 如果第 12～17 秒是另一個負重狀況，再把時段數量調成 2，新增一組。其餘時間不用填，沿用預設。
4. 設定鏡頭同步、所需 RULA 靜態條件後按「啟動分析」。30 張中的每張照片會自動代入當下的負重與肌肉使用分數，並計算 RULA。
5. 若只有第 18 張另外有軀幹扭轉，才到「照片批次修改」選那張改一次；若有 5 張一起不同，也能多選／選範圍一次設定。

**重要：**「肌肉使用 +1」須依 RULA 規則與實際作業頻率／持續時間判斷，不能把「畫面中正拿重物」誤認為肌肉使用一定 +1。負荷加分也取決於重量、靜態／重複／間歇施力及衝擊等條件，無法可靠只靠單張圖片識別。

## 哪些補正自動、哪些仍要現場資訊？

既有影像自動判讀預設啟用：上臂外展、前臂跨中線／向外工作、軀幹側彎、頸部側彎（以上依賴可用正面影像）、上臂後伸、軀幹後伸、保守的頸部後仰估測（後三項依賴側面影像）。上臂、前臂、手腕、軀幹、頸部角度仍由 MediaPipe 估測。

**不應虛稱自動：** 肌肉使用、實際負荷重量、腿足是否真的受支撐平衡、手腕旋前旋後、手臂有無倚靠／支撐，以及沒有足夠視角時的頸部／軀幹扭轉，仍可能需要使用者的作業知識或預設設定。影像自動補正也不是「百分之百正確」的證明，關鍵姿勢與高風險結果仍建議抽樣複核。

## 已測試與限制

- Python 語法檢查、舊版回歸腳本、影片秒數區間邊界、重疊及非法分數、左右同步轉換、時段優先順序、個別照片人工覆寫、RULA 查表依賴、CSV／ZIP 格式與壓縮檔完整性。
- 使用 `111.zip` 的 30 筆真實同步時間表核對：例如以右側影片第 4～12 秒為負荷區間，實際有 10 個抽樣落入該區間，其他回到預設值。
- **尚未在 Streamlit Cloud 對整支實際工廠影片進行完整線上端到端驗收。** 程式功能測試通過不代表影像角度與人工量角一致，也不能保證完全沒有錯誤；正式 240 張研究前請先依《驗收清單》完成至少一次實拍測試。
